# מדעי התזונה — סיכום ושאלות 🍎

אתר לימוד אינטראקטיבי לבגרות במדעי התזונה (שאלון 798381).
עמוד יחיד (`index.html`), ללא תלות בשרת — נפתח בכל דפדפן.

## מה יש באתר
- **📖 מצב סיכום** — 13 פרקים מפורטים (מבוא, מערכת העיכול, אבות המזון, ויטמינים ומינרלים, מים, אנרגיה, מעגל החיים ועוד).
- **🎓 מצב שאלות** — מאגר שאלות בגרות ממוין לפי נושא, עם תשובות נפתחות.
- **🔍 חיפוש** בתוך הסיכום ובתוך השאלות.
- **🔗 ניווט צולב** בין החומר בסיכום לשאלות התרגול בכל נושא.

## נגישות והקראה ♿
כפתור הנגישות (♿, פינה שמאלית-תחתונה) מאפשר:
- **🔊 הקראה קולית** בעברית של כל פרק וכל שאלה+תשובה (Web Speech API), עם השהיה, עצירה ובקרת מהירות.
- **גודל טקסט** — הגדלה / הקטנה.
- **ריווח מוגדל** ידידותי לדיסלקציה (ריווח שורות ואותיות).
- **רקע נקי** — הסרת הרקע המנוקד להפחתת עומס חזותי.

ההגדרות נשמרות בדפדפן בין ביקורים.

> ההקראה נשענת על קול עברי המותקן במכשיר (למשל *Microsoft Asaf* ב-Windows). ללא קול עברי מותקן ההקראה עלולה שלא לפעול בעברית.

## הפעלה מקומית
פשוט לפתוח את `index.html` בדפדפן (Chrome / Edge מומלצים להקראה).
